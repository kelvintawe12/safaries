# Kivu Safaris

Kivu Safaris is a legally registered tourism company based in the Kivu region of Eastern Congo (DRC). Our mission is to showcase the natural beauty, cultural richness, and hospitality of Kivu through sustainable and community-driven travel experiences.

## Features

- Explore handpicked featured tours and custom-made safari experiences
- User registration and booking system for tours
- Detailed tour pages with descriptions and images
- FAQ, Privacy Policy, and Rules pages for customer information
- Contact form for inquiries and support
- Gallery showcasing the beauty of the Kivu region
- Multi-language support with language context provider
- Responsive design with modern UI components and animations

## Technologies Used

- React 18 with TypeScript
- Vite as the build tool
- React Router for client-side routing
- Tailwind CSS for styling
- Framer Motion for animations
- React Hook Form and Zod for form handling and validation
- Lucide React icons
- jsPDF and QRCode for generating receipts
- Jest and React Testing Library for testing

## Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   cd kivu-safaris
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Run the development server:

   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173` (or the port shown in the terminal).

## Building for Production

To build the project for production, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## Project Structure

- `src/` - Source code including components, pages, contexts, hooks, data, services, and utilities
- `public/` - Static assets like images
- `README.md` - Project documentation
- `package.json` - Project metadata and dependencies
- `vite.config.ts` - Vite configuration
- `tailwind.config.js` - Tailwind CSS configuration
